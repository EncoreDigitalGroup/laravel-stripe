# Architecture decisions

This directory holds accepted Architecture Decision Records (ADRs). Plans in `docs/_planning/` are temporary delivery scaffolding.

Create an ADR for a public contract, package-wide runtime choice, or meaningful cross-cutting trade-off. Do not create one for a local implementation detail.

Name project ADRs `NNNN-<slug>.md` and use this structure:

```md
# NNNN - Short decision name

Status: Accepted

## Context

## Decision

## Consequences
```
